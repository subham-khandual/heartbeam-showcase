🌌 My Little Star — 3D Baby Photo Gallery Website
A futuristic and emotionally designed 3D Baby Photo Gallery Website built using React, Three.js, Framer Motion, and Tailwind CSS. This immersive web experience showcases adorable baby boy memories through a stunning rotating 3D carousel, cinematic animations, glowing UI effects, and smooth interactions inspired by premium Apple-level design aesthetics.
✨ Features
🎠 3D Rotating Baby Photo Carousel
🌌 Dark futuristic aesthetic with neon glow effects
💎 Glassmorphism UI cards and floating panels
🪄 Smooth animations using Framer Motion
🎇 Floating hearts, sparkles, and particle effects
🎵 Background music toggle button
🖼️ Fullscreen image preview modal
🧸 Stylish Baby Milestones section
🖱️ Mouse movement parallax interactions
📱 Fully responsive for mobile & desktop
⚡ Smooth page transitions and scroll animations
🌈 Realistic shadows, reflections, and depth effects
💫 Hover zoom and glowing image effects
🚀 Elegant loading screen animation
